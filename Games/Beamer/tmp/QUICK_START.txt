👋 HELLO WIKINGER-TEAMS!

Willkommen zur überarbeiteten Version mit modernem Buzzer-System,
Soundeffekten und zwei separaten Websites für Publikum & Moderator.

===============================================
🚀 LOS GEHT'S – 5 SCHRITTE
===============================================

SCHRITT 1: Zwei Browser-Fenster öffnen
──────────────────────────────────────
Fenster A: file:///path/to/beamer.html
   → Diese Website wird auf dem BEAMER angezeigt
   → Vollbild (F11)
   → Zeigt Teams, Spielnamen, Punkte, Buzzer-Anzeige

Fenster B: file:///path/to/moderator.html
   → Diese Website auf LAPTOP/TABLET des Moderators
   → Zur Spielsteuerung & Punktvergabe
   → Hier passiert die Kontrolle


SCHRITT 2: Team-Namen eingeben (Beamer)
────────────────────────────────────────
Beamer-Website:
  - Team 1 Name: [Text eingeben] z.B. "Drachen"
  - Team 2 Name: [Text eingeben] z.B. "Wikinger"
  - Team 3 Name: [Text eingeben] z.B. "Götter"
  → "SPIELEABEND STARTEN" Button klicken


SCHRITT 3: Buzzer testen (Moderator)
─────────────────────────────────────
Moderator-Website (rechts):
  → Im Info-Box "Audio" Button "🔊 Buzzer Test" klicken
  → Drücke die Tasten 1, 2, 3 auf Tastatur
  → Browser-Konsole (F12) sollte zeigen: "Team X buzzed!"


SCHRITT 4: Spiel auswählen (Moderator)
───────────────────────────────────────
Moderator-Website (Mitte):
  → Klick auf eines der Spiel-Kacheln
  → INFO-Panel zeigt Regeln
  → Beamer-Website zeigt das aktive Spiel


SCHRITT 5: Spielen & Punkte vergeben!
──────────────────────────────────────
Moderator:
  → Timer nutzen (Space zum Starten/Stoppen)
  → Punkte eingeben (rechts, Score-Grid)
  → "Score Input" ändern: +1 oder +5 Punkte Button
  → Nächstes Spiel wählen

Beamer:
  → Teams sehen großes Spiel-Display
  → Buzzer-Anzeige wenn Team buzzert
  → Punkte oben rechts aktualisiert

===============================================
🆘 HÄUFIGE PROBLEME
===============================================

Q: Buzzer funktioniert nicht!
A: → Moderator: "Buzzer Test" Button drücken
   → Taste 1 drücken
   → Browser-Konsole (F12) anschauen
   → Sollte "Team 1 buzzed!" anzeigen

Q: Sound funktioniert nicht!
A: → Moderator: Lautstärke-Slider erhöhen
   → "Beep testen" Button
   → Browser-Lautsprecher checken
   → In manchen Browsern muss Audio "freigegeben" werden

Q: Beamer und Moderator sind nicht synchron!
A: → Das ist aktuell normal (mit localStorage)
   → Einfach die gleichen Teamnamen verwenden
   → Punkte müssen manuell eingegeben werden
   → (WebSocket-Version kommt später)

Q: Spiel-Auswahl wird nicht angezeigt!
A: → Fenster aktualisieren (F5)
   → Bei Beamer: "SPIELEABEND STARTEN" klicken
   → Bei Moderator: Spiel-Kachel anklicken

💡 TIPPS FÜR ERFOLGREICHE NUTZUNG
===============================================

VORBEREITUNG:
  ✓ Buzzer testen BEVOR das Event startet
  ✓ Team-Namen vorbereiten

  ✓ Lautstärke für Gewinner-Sound erhöhen 🎉


===============================================
📝 REGELWERK-KURZÜBERSICHT
===============================================

DIE BERGUNG
  Gegenstände ausrufen → Team buzzert → Bringt Ding hin
  → 3 Runden

DER SCHMIED
  60 Sekunden schlagen! Wer drückt am meisten?
  → Schnelligkeit zählt!

DAS ANKERTAU
  Tauziehen in 3 Matches (1vs2, 1vs3, 2vs3)
  → 5 Sekunden pro Match

DIE EISERNE RATION
  Keks auf Stirn, ohne Hände in den Mund!
  → Fallt runter = raus

RAT DER ÄLTESTEN
  5 Quiz-Fragen, Team buzzert & antwortet
  → Richtig = 1 Punkt

DER FJORDKURS
  Timer läuft, auf 30 Sekunden genau stoppen!
  → 3 Versuche, wer am nächsten?

DAS TURNIER
  Klobürsten-Klau-Spiel! Teams kämpfen um Bürsten
  → 3 Minuten

DER SCHILDWALL
  Wandsitzen 90° Winkel, Rücken an Wand
  → Wer hält am längsten?

DER BLINDE WÄCHTER
  Einäugiger Wächter mit Schwimmnudel
  → Gegner müssen Buzzer drücken ohne Schlag


JOKER-SPIELE ✨
  Einfach → Team bekommt Punkte!
  → Nichts zu tun, einfach Lucky!
