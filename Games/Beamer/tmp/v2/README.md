## 🎯 WORKFLOW

1. Team-Namen eingeben (oder Standard nehmen)
2. **ZUR FELDSCHLACHT** klicken
3. Spiel aus Grid wählen
4. Spiel spielen (Moderator erklärt Regeln)
5. Punkte mit **Klick** vergeben (Team wird highlighted)
6. **WEITER** klicken
7. Nächstes Spiel wählen
8. Nach letztem Spiel: **ZUR SIEGEREHRUNG** klicken
9. Sieger wird angezeigt
